Questions

Do I need to be technical?

No. If you can open a file and fill in a form, you can use these tools. Each one ships with a one-page guide.

Where is my data stored?

In your browser on the device you use. It does not sync between devices on its own; use the backup file to move it. Clearing your browser data removes it, so keep a backup.

How do I pay and get the tool?

Each tool page has a secure card checkout run by Stripe. Card details never touch this site. The download link arrives after payment.

Who do I contact for help?

Open a request on our support page. Requests there are public, so never post card details or order numbers.
